### Welcome to XlCalcNetDocsOnline!
The main goal of XlCalcNet (an addin for MS E**x**ce**l** and LibreOffice **Calc**, based on Python**Net**) is to enable the use of functions written in CPython or C# within spreadsheet formulas. It is therefore assumed that MS Excel (2010 or later, 64 bit) and/or LibreOffice (7.0 or later, 64 bit) are installed on the users system, running under Windows (7.1 or later, 64 bit), with .NET Framework 4.8/4.8.1 installed.

The manual is available online in html format: [XlCalcNet.html](https://duhadler.github.io/XlCalcNetDocsOnline/); it can be downloaded as a folder for offline use.

The manual is also available separately as pdf file: [XlCalcNet.pdf](https://github.com/duhadler/DocsXlCalcNet/raw/master/pdf/xlcalcnet.pdf), which is intended to be downloaded for offline use with a proper pdf reader.
