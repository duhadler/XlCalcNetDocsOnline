Torus knot 3:2
--------------------------------------------


Some text

See also: https://mathworld.wolfram.com/TrefoilKnot.html

See also: https://katlas.org/wiki/T(3,2)


An example in C\#

.. code-block:: csharp

    double R = 100;
    double r = 25;
    double p = 3;
    double q = 2;
    var x = ((R + r * Math.Cos(p * t)) * Math.Cos(q * t)) / 50;
    var y = ((R + r * Math.Cos(p * t)) * Math.Sin(q * t)) / 50;
    var z = (r * Math.Sin(p * t)) / 50;
